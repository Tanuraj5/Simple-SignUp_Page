# Sign Up Page UI

A simple and modern sign-up page created using HTML and CSS.  
This project focuses on clean layout, Flexbox-based form alignment, and modern UI styling.

## Features
- Centered and responsive sign-up form
- Side-by-side first name and last name inputs
- Clean blue color theme
- Hover effect for better UX
- Beginner-friendly and well-structured code

## Technologies Used
- HTML5
- CSS3 (Flexbox)

## Purpose
This project was built as part of my frontend learning journey to practice form layouts and UI design.

## Future Improvements
- Form validation using JavaScript
- Backend integration
- Dark mode support
